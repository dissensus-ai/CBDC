# Manuscript build and package identity

The September canonical draft is `manuscript/main.tex`, not the root August manuscript. The PDF is named `manuscript/main.pdf` on this review branch. All scientific tables are inputs generated from `evidence/adjudicated-results.json` / immutable August raw records, and all three figure PDFs are generated by `detection/revision20260912/plot_figures.py`.

The separate minimal arXiv source archive is created after the final PDF and numerical checks. It includes source, bibliography, generated table fragments and figure PDFs. Its clean extraction/build is checked independently from this working tree. The archive's hash and the local review-branch commit are provided in the release handoff; no arXiv upload or public release is implied by creating a source archive.
